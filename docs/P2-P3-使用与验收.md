# 测评、H5、AI接入与界面重排：使用和验收

日期：2026-09-17。本轮交付可操作的 P2 自评链路与 P3 AI 接入基础，不代表整个需求包所有阶段完成。

## 现在怎么用

管理后台：本机打开 `http://127.0.0.1:3100/`。六个主入口为工作台、人才档案、岗位管理、测评中心、AI 助手、设置。

### 发起测评

1. 测评中心 → 发起测评，选择人员；无简历的员工可以点“新增无简历人员”，填写姓名及处理依据。不会伪造简历。
2. 填写用途、有效天数；有招聘申请时可以关联其固定岗位/简历版本。员工自评无需关联岗位。
3. 创建后显示本次专属答题链接、独立报告链接和六位访问码。链接和访问码建议分开发给本人。系统不代发消息；原始凭据只在创建时返回一次。
4. 本人无需后台账号，输入访问码，阅读自愿说明后答题。每组三题；保存进度/下一组会同步，重新打开并输入访问码可续答。没有保存的答案只留在当前页面，断网时不要关闭。
5. 全部24题答完才能提交。提交后自动计分并显示本人H5报告；后台可查看进度及报告。报告可调用浏览器打印/保存PDF。
6. 撤销立即阻止该邀请继续访问。人才负责人可通过页面内确认删除当前数据库中的本次邀请、答案及报告；离线备份和已下载文件不随此删除。

当前是齐论原创“工作偏好自评 1.0.0”：八维各三题、五级自评；维度均值线性转换到0–100，保留两位小数。所有题目、计分方法和边界已固定，并保存到邀请快照。不是高禾原版，不是七模块完整心理量表，没有常模、效度或招聘预测声明。报告不输出人格招聘建议，也不自动筛人。

### 内网手机访问

本机当前IPv4是 `192.168.0.161`，生成链接的前缀为 `http://192.168.0.161:3100`。手机需要连到同一网络，电脑和服务进程保持运行。IP变化后需要修改 `.env` 的 `H5_ORIGIN` 并重启，已发旧地址也需通知接收者更新主机地址。

本轮按用户授权启用 `LISTEN_HOST=0.0.0.0`；Windows防火墙规则 `Qilun H5 LAN 3100` 仅放行 Node 程序的 TCP3100、来源 LocalSubnet。管理API根据真实socket来源限制为本机，不能通过伪造转发头从内网登录后台。H5 API另行使用专属凭据与来源校验。

这是内网HTTP开发版，链路不是TLS加密；不适合作为公网或敏感人员资料的生产服务。外网需单独的HTTPS部署与验证。本轮没有对互联网开放端口或部署。

### 接入 AI

设置 → 模型与接入，配置默认供应商、模型ID、API Key、提示词、累计预算及输入/输出价格（美元/百万token）。也可给六种功能分别配置，或恢复继承默认模型。

供应商实现依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。仅支持固定官方HTTPS端点、支持Chat Completions JSON输出的模型；不是所有模型ID都兼容。价格由用户按当前供应商账单填写，不硬编码宣传价格。

Key以AES-GCM加密落库，前端只接收是否已配置；变更供应商时必须输入新Key。仅人才负责人可修改设置。点击连接测试才会发起真实供应商请求，使用合成材料，也会计费用。

AI助手支持岗位优化、简历材料分析、面试提纲、面试文稿分析、综合证据评估、员工发展沟通。当前工作流是手工粘贴已获授权的材料，确认发送给所配供应商后执行。材料逐段编号，每条分析/建议必须带能在输入中找到的逐字引用，否则整次输出拒绝展示。引用核验不等于自动证明推论正确，仍需人工复核。

调用前预留预算，配置锁防止并发超预算；继承默认的调用共享默认预算。返回usage时按用户配置价估算，缺usage/失败/中断时保留未知费用预留，不自动重试。程序重启将进行中的调用标记为中断。当前不是持久化队列，不承诺自动续跑。账单以供应商为准。
