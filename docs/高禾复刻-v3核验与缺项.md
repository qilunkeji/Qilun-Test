## 三、为什么现在不能声称计分一致

对包内存档作答进行离线重算：排除invalid-baseline记录及360条不完整/无效行，以完整180题答案去重得到9,196组。未发现同一答案对应不同Top5的冲突。比较使用精确分数，允许第五名边界并列，未伪造同分决胜顺序。

| 回放指标 | Book118分母 | 已定位关系数分母 |
| --- | ---: | ---: |
| Top5集合完全相同（显示平局按表序） | 7,036 / 9,196 | 7,056 / 9,196 |
| Top5集合相容（允许并列） | 7,211 / 9,196 | 7,385 / 9,196 |
| Top5顺序也相容 | 4,784 / 9,196 | 4,839 / 9,196 |

即使采用较高的“允许并列集合”口径，也仍有1,811组不相容。这些是外部网站历史取证答卷，包含推导计分表时用过的样本，**不是独立验证准确率，更不是高禾复刻率**。

可复查的非平局反例：

- 文件：`20260922-yuzeli-achievement-candidates-v3-top5-clean.csv`
- 运行号：`achieve-v3-q134B-positive`
- 原存档返回：前瞻 → 成就 → 个别 → 体谅 → **关联**
- v3计算结果：前瞻 → 成就 → 个别 → 体谅 → **搜集**
- 分数：关联28/18；搜集27/17，二者不相等。已进一步对照相应 `20260922-yuzeli-achievement-candidates-v3-raw.jsonl` 的 `result_response`。

此外，v3表的q29统率权重为3/2/1/-1/-2，而旧前68题映射文稿给出不同负分；伯乐的分母16与已定位17条关系、追求的分母19与已定位18条关系存在差异。应用分别保留两种分母用于核验，没有凭样本拟合后宣布找到原算法。

现有材料能确认“一些题目、输出字段和样本返回”，不能唯一确定“所有可能答案到整套输出”的函数。仅凭PDF反推时，多种计分规则都可能产生同样的几个样本，却在其他答案上不同。
