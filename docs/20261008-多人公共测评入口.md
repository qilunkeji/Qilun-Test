# 多人公共测评入口与招聘专属邀请

用户授权修改、验证并执行上线。本轮基于已上线邀请一键分享继续开发，无远程、不推送；不重置账号、数据库或密钥，不修改001–011已应用迁移。

## 行为

- 测评中心“发起测评 → 邀请方式”：指定人员为专属邀请；外部公共入口无需选择人员，创建一个多人登记入口，锁定用途、项目组、测评版本和登记截止时间。
- 公共链接/访问码只允许查看登记说明并建立本人答卷，不可读取任何个人答卷。每次登记要求本人姓名、电话、出生日期及同意；同名不合并、不自动创建虚构简历档案。每位参与者拥有独立的答卷ID、个人链接及访问码，独立自动保存、计分和报告；可后补手动绑定档案。
- 浏览器随机生成256位个人标识作为个人续答秘密。服务端只保存摘要，用服务器密钥和入口ID派生个人PIN；重复提交同一登记标识幂等，不修改旧资料。服务端入口行锁避免并发重复。不会通过姓名、手机号查找或合并他人记录。
- 此浏览器仅保存个人续答凭据/待登记标识，不保存姓名、电话、出生日期。再次打开公共入口需确认“继续本人的测评”；共用设备可选择“我是另一位参与者”。个人信息页内可复制个人链接和码，跨设备凭个人信息继续；清理浏览器后若未保存个人凭据，需联系管理者，不提供姓名/手机号免验证找回。
- “停止新登记”只关闭公共入口的新登记，不删除既有个人答卷；个人链接仍按各自期限访问。个人期限为原公共入口的截止时间，个人数据保留365天；无业务参与人数上限，仍有每IP每分钟60次公共请求的防滥用限制，不承诺无限并发。
- 个人答卷按入口指定项目组进入测评列表，后台名称取本人资料；候选档案仍需明确人工绑定。
- 招聘申请列表、人才详情的岗位申请行新增“发起测评”，自动关联当前人员和招聘申请，7天专属链接；不会误绑定其他申请。依据现有服务端权限/人员保留期限制，不免授权。
- 额外十页AI解读仍由既有外部智能体流程处理；固定七模块报告提交时自动生成，不改计分或重新训练模型。
