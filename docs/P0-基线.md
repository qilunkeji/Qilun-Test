## 数据模型与权限范围

tenant → staff → sessions；tenant → jobs → immutable job_versions；tenant → candidates → candidate_sources/resume_versions/document_chunks；application 固定 candidate + job + job_version + resume_version，并以 batch 限制重复申请。

跨表使用组合外键约束 tenant 与所属人员/岗位。岗位版本、简历版本不可原地更新；新版本不改变历史申请。导入以本租户稳定来源 ID 与内容摘要幂等，同名不自动合并。来源、用途依据、保留日期必填。联系方式加密保存，单独读取并审计。过期资料不出现在正常查询中；物理删除闭环属于 P4，不能将隐藏视为已删除。

每次写入与必要审计同事务完成。P1 不调用 LLM、不输出测评分、不抓取渠道、不发消息。后续范围按原验收 P2–P6 保留。
