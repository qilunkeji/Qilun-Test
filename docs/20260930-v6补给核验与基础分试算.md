## 实现与使用

- `packages/assessment-engine/gh-server-evidence.ts`：版本固定的基础分纯函数、输入校验、最新缺项。
- `data/gh-server-rules.json`：允许导入的题号、映射、数值规则、价值词库和公共维度名称，不含个人答案、姓名或业务标识。
- `data/gh-v6-audit.json`：聚合核验结果、校验值、限制，不含个人记录。
- `GET /api/v1/assessment/gh-evidence`、`POST /api/v1/assessment/gh-evidence/score`：原有登录、业务角色、CSRF；no-store；不保存答案、个人分或调用外部AI。
- 页面支持合成样例、版本化JSON答案导入、基础分及287项贡献导出。只接受完整277题及10个不同价值题号和1–10全排列；拒绝缺答、未知题、混版本、非法编码、身份绑定及客户端用途覆盖。
- 正式报告、正式发布与匹配接口仍409阻塞。旧153题接口不悄悄改变协议，外部180题不混用。本轮未把基础分自动填进原PDF留白：基础分并不等于全部最终报告分。

## 离线复现

原件解包在私有`.local/evidence-20260930-v6/`和`.local/evidence-20260930-v3-base/`；只读使用，不执行包内run_all.sh、联网探测或会覆盖证据的main函数。

```sh
python3 -B scripts/import-gh-evidence-v6.py '<外层v6解包根目录>' '<嵌套主包v3根目录>'
python3 -B scripts/audit-gh-derived-evidence.py '<嵌套主包v3根目录>'
pnpm build
pnpm test
```

第二步只调用三份经审阅且SHA锁定的回放模块纯函数；源码变动时拒绝执行。必须按顺序完成两步以生成完整核验摘要。原清单在导入及复验后再次校验通过。私有答案夹具写入`.local/evidence-20260930-audit/`；缺少该目录的电脑会显式跳过私有158项回归，不能冒充重跑过真实样本。
