完整读取五份分析文稿及十一份 PDF 的全部 56 页文本，并渲染、目视核对五份人才报告的动机图表页。五份文稿与原资料包对应文件哈希一致，没有新增逐题计分或总匹配规则。十一份 PDF 中两份数据报告提取文本相同，因此有十份不同文本。

```powershell

node --experimental-strip-types scripts/verify-report-samples.ts
```
