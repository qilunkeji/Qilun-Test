# 前后台权限与 H5 体验调整

## 用户要求与范围

在现有系统上继续，不重新做测评，不改原题、五档选项编码、计分、价值选择/排序定义。日常页面只保留邀请和结果；原理/证据/试算及原版留白模板放到负责人后台。手机答题页面隐藏模块分类，改横向圆点、自动保存和准确续答；欢迎页以齐论内部性格与发展测评介绍为主。

## 实现

- `测评中心`只展示邀请、记录、已完成结果。已完成七模块数据表仍可正常查看，不把结果查看误当模板调试。
- `设置 → 测评后台`按需加载，只有`talent_lead`可见；内部保留原版版式与留白、规则核验、规则与依据。服务端18个规则/证据/试算/原稿接口同样只允许该角色，HR、运维、面试成员均403；普通角色的系统状态不返回规则核验条目。HR不能删除答卷的既有权限也同步到按钮。
- 中央账号映射不改：负责人仍须中心`talent.view + talent.manage`授权，通用中心管理员不自动获得权限。每次接口请求仍实时检查中心角色。
- 当前277题H5显示Part A / Part B和题号，不显示职业定位等分类。每题保留原五档选择，手机也横排圆点；Part B的分组选5、20选10及最终排序语义不变。
- 每次选择、改排序或换页约250ms后自动保存；单邀请串行写入最新revision，旧回包不能误标新答案已保存。失败不清空草稿、不冒充成功；超时、断网、失焦/退出保护，网络恢复时尝试保存。若回包丢失，只在服务器内容与已发送快照完全一致时确认成功，绝不合并覆盖另一页面的不同内容。
- 新增008迁移，仅加`ui_progress`显示游标（阶段、题组、词组），不参与计分或答案哈希；提交后不可变。001–007原文件不改。游标存在时跨设备恢复准确位置；老邀请无游标则从未完成题/选择步骤继续。链接与PIN仍必需，不把访问码或答卷写入浏览器长期存储。
- 欢迎页为正式齐论介绍、建议约30分钟、认真作答/遵循真实想法；不展示277题、还原进度或算法技术说明。简短参考用途/隐私说明仍在，完整参与须知可展开；启用估计时说明并在结果中保留估计标记，不把估计伪装成确定能力分。
- 本轮只调整277题体验，24题独立版原流程保留，不与277题混用。
