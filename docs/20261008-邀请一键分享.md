# 测评邀请一键分享

本轮仅本地修改，未部署；线上仍为 external-agent-v3。新分支 codex/invitation-one-click-share，无远程配置，不推送。

## 使用变化

创建邀请后展示一段完整邀请信息，点击“复制链接和访问码”一次复制原答题链接、六位访问码和简短说明，可一起私发给本人。不把访问码写进 URL、日志或浏览器持久存储。复制被浏览器拒绝时，自动选中文字并提示手动复制；收起凭据后原有一次性显示规则不变。

移除创建成功页和本人结果页的额外报告链接展示。提交完成后已有服务端计分和报告保存逻辑不变，立即显示报告；原测评链接输入访问码后可再次查看，后台已完成列表可查看。历史独立报告 URL/API 不删除，旧链接继续兼容。此次没有新增生成步骤，不将固定数据报表生成交给外部智能体。

不改计分、答案保存、访问码鉴权、保留期限、数据库迁移、账号、密钥、唤醒配置或线上数据。

## 验证范围

新增邀请信息/实际 HTML 和前台入口测试；隔离浏览器覆盖复制内容、复制失败全选、收起凭据及原有分组/后补绑定流程。最终177项自动测试全部通过（0失败/跳过），类型检查、Vite构建及19组隔离浏览器检查通过。全部浏览器业务请求使用虚构替身并阻断外网，未写真实业务材料。

发现原 IAM 测试的随机误报：篡改签名固定写 X，而随机签名首字符偶尔就是 X，导致测试实际未篡改。测试改为 X/Y 中不同于原首字符的值，始终改变签名；生产 IAM 逻辑完全未改。
