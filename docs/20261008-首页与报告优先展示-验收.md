# 首页、报告优先展示及本人资料

## 本轮实现

首页仅保留“人才管理工作台”、一句说明、新建岗位/测评中心入口；白底、石墨文字、齐论红按钮，官方光带缩为右侧装饰，390px隐藏装饰。没有改官方素材。新增home-refinement.css限定首页和报告外层。

277题报告打开默认一页数据表，详细七模块阅读版及说明放在底部原生details折叠中。能力推算属性和用途限制保留在详细说明及页脚，不冒充原版已验证。历史24题的独立报告未改。

计算报告页头用独立SVG文字层重排姓名、脱敏手机号、出生日期、上海时区测评日期/时间、已记录答题用时，修复姓名日期覆盖原稿标签；原稿矢量底图、曲线、排序、分数及词库不变。空白/录入样例模式不套用这个新计算页头。

H5欢迎页增加手机号码及出生日期，本人确认后加密保存到本次邀请；手机号报告只回传脱敏文本，不自动写入人才联系方式或发送给外部模型。已同意但未完成的旧答卷，继续前补本人资料；已提交答卷不改、不强制重新填写、不回填年龄/手机。

新增009迁移，仅新增profile_cipher、active_seconds、timing_updated_at和提交后不可变保护；001–008不改。新资料用已有32字节服务端密钥和tenant AAD加密。服务端校验手机格式、真实日期/非未来/1900下限、邀请有效性/保留期限/版本，同意更新加行锁，已提交拒绝改写。报告不回传密文或完整手机号，原有同租户/角色限制保持。

计时为前台可见、最近两分钟内有操作的累计秒数；每30秒随原串行保存队列同步，切后台/退出时尽力提交。服务器不接受倒退或任意增加，按服务端经过时间最多120秒校验单次增加。提交冻结、重新进入读取已存时间。不是从邀请创建到提交的自然时差；关闭期间不计，未同步的尾秒可能丢失，历史缺失不追溯伪造。

逻辑一致性仍没有经过验证的原评分规则，明确显示“未评定”，不选低/吻合/高、不凭作答时长或能力值推断一致性，不新增未经检验的评分公式。
