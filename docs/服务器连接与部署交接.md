在本机安装私密包里的密钥及主机公钥到独立文件后，连接命令为：

```sh
ssh -F connections/ssh_config.example qilun-talent
```

登录后：

```sh

systemctl is-active qilun-talent.service
systemctl status qilun-talent.service --no-pager
journalctl -u qilun-talent.service --since '30 minutes ago' --no-pager
```

日志可能含业务上下文，交回排错时先按问题范围截取。先本地跑build/tests，确认版本后再发布。

## 发布与回退原则

现有activate脚本是历史一次性发布记录，均带旧版本/摘要保护，不可重跑。新的修改需准备新的发布目录或仅前端增量包，记录当前版本、变更和回退方式。源码有最新改动，不等于服务器current里保存完整Git历史；以本包manifest和bundle为开发基线。

纯前端发布保留旧哈希资源并原子切入口；API或数据库迁移发布须让PGlite保持单实例，停止唯一服务后备份shared，再切换并验证。不能复制正在运行的PGlite文件作为可靠备份。失败回退通常切代码并保留最新业务数据，不用旧备份覆盖新增答卷。

保留全部001–015已应用迁移、原账号、加密密钥和固定规则。禁止在生产运行本地init、更换现有加密密钥或使用协作者自己的开发库覆盖线上。其他域名、IAM中心及网关共享服务不属于人才系统的默认修改范围。

Git目前没有远程地址。团队确立私有仓库后再添加对应remote；本次只生成本地交接包，未上传源码/凭据到公共位置。
