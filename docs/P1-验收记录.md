# P0 / P1 实际开发验收记录

日期：2026-09-17。环境：Windows / Node.js v24.16.0 / PGlite 0.5.8。测试均用虚构资料。**交付 P1 核心链路，不表示全部需求或 P1 所有扩展项完成，不具备生产上线条件。**

## 已实现和实测

- 内部随机账号初始化、密码 scrypt、数据库会话、HttpOnly Cookie、CSRF/Origin 校验、登录限速、退出撤销。
- 岗位建立、列表搜索与分页、岗位新版本、expected_revision 冲突保护；数据库触发器保护不可变版本。
- 有来源/用途/依据/期限的人工简历导入；当前 TXT/粘贴文本。原文、SHA-256、行号片段保存至服务端数据库。
- 同源 ID + 内容哈希幂等；并发首次导入只建一份；同名新来源不自动合并；同源姓名冲突拒绝。
- 人才主档、多简历版本、多岗位申请；岗位/简历更新不改变已有申请快照；错绑人员/版本被拒绝。
- 租户过滤与组合外键；HR/人才负责人业务权限；运维/面试官默认拒绝业务读取；加密联系方式独立读取并审计。
- 过期资料限制访问（未物理删除）；审计不存简历全文、手机号、密码或会话 Token。
- 中文管理后台真实操作、错误和空状态；明确显示后续功能/外部依赖未完成。

## 实际命令与结果

PowerShell 中 npm 使用绝对命令 `& 'E:/软件安装--26年6月/npm.cmd'`，下表用 npm 缩写。

| 命令/操作 | 实际结果 |
|---|---|
| `Get-ChildItem -Force`、`rg --files` | 初始为空，无现有代码或隐藏 Git 仓库 |
| `git status --short --branch`、`git remote -v` | 未执行成功：git 不在 PATH；常见 Git 路径未找到 |
| `Expand-Archive` 用户指定 ZIP | 成功；未覆盖已有工程 |
| `npm view` 六个运行/构建依赖版本 | 首次 npm 缓存写入受沙箱限制；取得批准后成功 |
| `npm install --save-exact` | 安装 104 个包，生成锁文件；该次安装审计报告 0 vulnerabilities（不代表完整安全审计） |
| `node scripts/verify-evidence.mjs` | 五份 SHA-256/字节数通过；历史原始 JS/JSON 目录未找到 |
| `npm run build` | 初次缺少 CSS 模块类型声明失败，补充 Vite client 声明后成功；最终 TypeScript + Vite 构建通过 |
| `npm test` | 首轮 15/15；新增并发导入/行数限制并加强拒绝审计后，最终 16/16，0 失败/跳过 |
| `npm run init` | 创建本地开发组织及随机账号，未自动创建候选人 |
| `npm run dev` | 启动 http://127.0.0.1:3100；最终服务重启成功，原记录保留 |
| 内置浏览器 UI 操作 | 登录、新建岗位、导入、申请、编辑 V2、旧申请 V1、重载/重启后读取全部完成 |

最终测试耗时约 10.3 秒；这不是压力测试。完整结果：[测试日志](qa/P1-tests.txt)、[构建日志](qa/P1-build.txt)、[证据核验](qa/P0-evidence.txt)。

## 浏览器验证

使用 Codex 内置浏览器，实际填写并提交表单，没有用浏览器内存假数据。一个岗位和一个候选人均标「【虚构验收】」，来源记录为虚构测试。岗位编辑生成 V2 后，申请仍显示 V1；文稿 `<script>` 以转义后的纯文本显示。服务重启后数据库计数仍为 1 岗位/1 档案/1 申请。

检查 1440 宽档案详情、1280 宽申请列表，以及 390 宽管理后台工作台。1280/390 未见整页横向溢出；窄屏表格允许容器横向滚动。当前浏览器 error 日志为空。此处是管理端窄屏检查，**不是独立 H5 或微信真机验收**。
