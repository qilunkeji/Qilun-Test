# 招聘优化与面试评估 · 2026-09-18

## 使用
招聘优化：左侧反复添加公司介绍、产品、团队福利和岗位参考，保存后勾选参与本次生成的资料。右侧填写岗位、地点、月薪区间、年薪月数、经验、学历、风格和补充要求。模型使用“招聘优化”独立配置或默认配置。结果提供文案、引用、待确认项、复制及历史记录。资料支持粘贴、UTF-8 TXT/Markdown，每份5–8000字，最多选择10份；合并需求限制12000字。PDF、Word暂需复制文字；上传后需点击保存。公司资料加密存储，归档不等于物理删除。

面试评估：独立导航，新建面试时选择已有岗位申请，锁定该申请的岗位/简历版本，可选择同一人员且同一申请或未关联申请的已完成测评。填写1–6项岗位能力标准及权重，选择10或20个问题。标准在本次档案中固定，修改标准需建立新面试。

提问使用“面试提纲”配置，材料包含岗位、简历、能力标准和可选测评。生成结果含问题、目的、追问和引用。文稿支持粘贴或UTF-8 TXT/Markdown，最多16000字；保存时校验文稿版本，拒绝覆盖其他人的更新。

评估使用“综合证据评估”配置，输入只包含岗位要求、人工标准和面试文稿，不发送人格测评/简历作为打分材料。评分0–4：明确未达要求、基础做法有关键不足、独立常规任务、复杂任务及成果、可复核成果与复盘迁移。每个已评分项必须引用面试文稿原句；服务端按人工权重计算参考分。未知项保留null，缺证时不生成完整总分，只显示证据覆盖权重。模型对语义、说话人及叙述真实性的判断仍需人工复核；分数不是录用概率，不自动筛选淘汰。

保存文稿后重新勾选模型发送授权，再生成评估。历史结果记录对应文稿版本与费用；历史结论不会假装对应最新文稿。模型记录保留策略沿用30天可见期限，面试访问随候选人保留期限限制；未实施自动物理清理。
