# 共用测评链接与免密码登记（已上线）

## 最终需求

按用户最后补充，不再使用专用链接，也不要求密码或访问码。测评中心、招聘申请与人才档案旁的创建操作统一生成可供一人或多人使用的共用入口；创建入口不预先绑定人员。每位参与者填写本人姓名、手机和出生日期，确认说明后建立独立答卷。后台名称、本人报告名称以参与者填写的姓名为准。关联人才档案是登记之后的显式核对操作，不按同名、手机号或链接自动合并或绑定。

## 实现

- `/assessment/invites` 和 `/assessment/public-entries` 均创建共用入口，仅返回可分享的入口链接，不返回个人链接、报告链接或访问码。旧客户端传来的人才/申请引用仍验证范围，但不会绑定整条入口。
- 所有 `/h5` 路径统一进入登记/本人续答确认页。新登记直接填写资料，未登记不会创建答卷；公共入口只能读取用途、名称、期限与同意版本，不能读取个人资料、答案或报告。
- 每次登记使用随机参与者凭据，在浏览器内保存；答题、自动保存、进度、计时、提交和本人报告仍按各自的答卷处理。分享按钮、地址栏保持共用入口，不展示个人凭据。
- 同一浏览器重开先显示上次参与者的姓名，必须确认本人后续答；“我是另一位参与者，另建答卷”会更换登记随机标识，包括不刷新页面时。丢失登记响应后的同一资料重试返回原答卷，资料变更拒绝误用旧标识。
- 后台保留项目组、分页、撤销/删除、后补关联与报告查看；已关联档案不改写姓名、原始资料、答案、计分或报告。

## 旧链接与迁移

新增015迁移，不改写001–014。旧单人链接映射成共用登记入口，其既有姓名、原始绑定、题包、答案、报告、凭据摘要和期限全部保留；新参与者从空答卷开始，采用现行固定V1.0。旧公共入口无需公共访问码；曾经发送的个人链接可打开其父登记入口，但URL单独不能读取旧答案。已在浏览器保存的旧个人续答凭据仍可经本人确认后使用。

原来的混合答卷保留在后台，不能可靠判断哪道题由谁填写，故不伪造拆分结果，也不将它转给新登记的人。旧单人历史报告不再凭共享URL打开，应在后台查看。

停止新登记不删除已有个人答卷。撤销/删除旧单人记录也停止由该记录转换的公共入口。访问期限、365天独立保留、授权档案保留期、租户权限和频率限制继续生效。

无需参与者输入密码不等于通过姓名证明身份：续答依赖本机浏览器保存的随机凭据。换设备、清除浏览器数据或在共用设备切换另一位参与者后，不能仅凭姓名找回旧答卷，需要联系管理者；参与者切换后的旧答卷仍在后台保存。未承诺跨设备免验证恢复。
