# 验收用例与阶段性交付

以下是待执行验收计划，不代表已经开发完成或测试通过。使用虚构数据；真实候选人资料需要批准的处理范围。

## 1. 分阶段交付门槛

| 阶段 | 可演示交付物 | 进入下一阶段门槛 |
|---|---|---|
| P0 基线 | 现有仓库说明、证据差距、数据模型、权限范围 | 不混淆原站已知/未知；不破坏原工程 |
| P1 档案主线 | 登录、岗位、岗位版本、候选人、简历、申请 | 两个租户隔离；同人多岗位；版本可追溯 |
| P2 H5与测评 | 专属邀请、答题续答、提交、发布校验、外部报告导入 | 防错绑、Token安全、缺规则不能发正式量表 |
| P3 AI工作流 | 模型配置、岗位优化、解析、初筛、提纲、文稿分析 | 真实已配置模型试跑；证据验证；失败可降级 |
| P4 招聘闭环 | 面试、音频转写、综合评估、人工决定、保留和删除 | 录音归属、决定权限、受众隔离、删除闭环 |
| P5 渠道与批量 | 已许可渠道适配、任务恢复、配额与500份目标 | 真实授权联调；无授权渠道明确禁用；不虚报处理数 |
| P6 正式规则 | 完整授权规则和真实黄金样本 | 分层回归通过；发布审批；报告用途正确 |

每阶段输出changed-files、命令和日志摘要、测试清单、截图、未完成项。不得以静态页面完成代替业务完成。

## 3. 性能验收记录格式

记录硬件、数据库版本、数据量、并发数、输入文件大小、供应商与模型、实际配额、测试时段、成功/失败率、P50/P95、Token/时长、成本口径。只测试本地导入不能宣称平台抓取吞吐；只有200条素材不能宣称500条全量测试已通过。

## 4. 停止发布条件

有跨租户访问、Key泄露、候选人与岗位错绑、结果被演示分数污染、未知规则被自动补齐、自动按人格淘汰、删除未闭环、未经许可平台获取或原站计分被虚假宣传为完整还原时，停止该能力发布。其他已验证模块可独立交付。
