# 齐论AI人才管理系统｜Codex开发资料包 v1.0

本资料包用于启动和验收开发，不是已经实现的应用源代码。当前外部平台没有完成联调，原测评的完整题库和后台规则尚未取得；包内不会把这些依赖伪装为已实现能力。

## 交给Codex的方式

将本目录放入要开发的工作区；同时打开或提供真实项目仓库。先发送 `00_Codex启动指令.md` 中的完整指令，让Codex依次读取其指定的文件，再开始分阶段编码。

没有既有仓库时可以新建项目；已有项目则先检查并增量修改，不删除重建。生产部署、外部真实邀约、平台付费解锁以及破坏性迁移需要单独确认。

## 必须区分的四件事

“看到资料”不是“获得批量采集许可”；“选项编号”不是“心理维度分数”；“有JSON格式”不是“AI事实正确”；“页面和演示用例通过”不是“真实平台已联调、原测评已完全复现”。

测评结果和招聘评价分层：自述性格及MBTI式偏好可以有来源地保存，并用于适当的发展/沟通用途；招聘初筛和人岗判断依据工作任务、技能、项目、作品与面试行为证据，由人决定下一步。

## 本资料包完成了什么

整理产品需求、工程边界、数据和接口设计、示例配置、提示词及验收计划。已对随包JSON与样例做静态校验；这不等于运行了业务代码、测评原脚本、实际模型或招聘平台接口。后续由Codex交付真正的应用代码和运行测试证据。
