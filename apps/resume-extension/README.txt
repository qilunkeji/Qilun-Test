齐论简历收集助手 0.1.0 — 本地验收版，未上线、未提交Chrome商店

安装：解压后在Chrome打开 chrome://extensions ，开启开发者模式，点击“加载已解压的扩展程序”，选择包含manifest.json的本目录。安装的实际扩展ID以Chrome显示为准。点击工具栏扩展图标打开侧边栏。

本地演示：在项目根目录使用Node24运行 scripts/demo-resume-library.ts（--experimental-strip-types），浏览器访问 http://127.0.0.1:3101/resume-library 。演示账号talent_lead，密码demo-resume-local。这是一次性内存虚构演示，不是生产账号。关闭进程即丢弃数据。

连接：登录演示网页，简历库 → 插件授权。输入Chrome显示的扩展ID，生成临时授权，复制至插件。系统地址填写 http://127.0.0.1:3101 ，点击“授权此地址并连接”。此授权只可导入、有效1小时、仅临时存于chrome.storage.session，浏览器重启/扩展重载会清除；网页可撤销。不要使用智能体写token，不要填写BOSS密码。插件地址支持指定线上域名是协议准备，不代表本轮已上线，线上当前不支持本接口。

收集：人工粘贴获准处理的文本，或读取200KB内UTF-8 TXT；填姓名、用途、保留期、来源稳定编号、处理依据及授权记录。未知源编号可为新记录生成独立编号，但之后更新需保持这个编号，否则不会去重。姓名相同不自动合并。点击预览，核对后确认导入。同源同内容不重复保存，同源新内容新增版本。仅摘要选择“仅摘要”。不自动导入或保留本地简历正文，确认成功后清空表单。

筛选：网页简历库勾选版本 → 按岗位分析 → 选择岗位固定版本、填写职责/必要条件/可放宽项、确认本次外部处理授权 → 提交。每份一个resume_job_screen任务，复用外部智能体MCP领取/提交协议；结果需严格引用，不自动拒绝、不发消息。演示进程的模拟智能体明确标注“模拟”，仅验证异步流程，不是实际AI质量。真实运行需智能体支持动态list_task_types里的新类型。

两轮操作：第一轮左侧“待看”保留其他简历，仅将“存在明确不符项”默认收起（可展开）；点击简历，中间读原文、右侧读建议与引用。人工查看后点击“进入第二轮”，待看分为“建议重点看”和“需要补充确认”，未完成任务另列等待结果。填写确认理由，点击“重点沟通 / 补充资料 / 暂不推进”仅在齐论记录；“回到BOSS”只打开BOSS网页，由你自行登录沟通。轮次与人工记录刷新后保留，可在右侧“历轮人工记录”展开查看。无唤醒配置时页面显示“已提交，约15分钟内处理，可以离开页面”；实际需智能体巡检，不承诺处理时限。

BOSS状态：公开找到的2019版官方协议第4节第8项限制未经许可第三方工具获取服务。尚未取得本企业授权或当前协议确认，无法证明允许页面读取。因此此版没有BOSS主机权限、content script、DOM采集、自动翻页、绕过风控、登录/嵌入、点击或发消息功能。手工复制/下载也须有相应许可与候选人资料处理依据；看见简历不自动等于可长期存储或外传。参见 https://www.zhipin.com/web/common/protocol/protocol-2019-09-30.html （历史版本，不冒充最新协议）。

删除：网页可删除未被招聘申请引用的简历版本、文本行及该版本关联筛选快照/结果/复核记录，并取消待处理任务。主档、其他版本、来源记录、非本筛选任务的材料、服务器备份和下载副本不在该操作范围。被申请引用的版本明确拒删，需负责人协调关联记录，不宣称全局删除。过期版本不再列出或发起分析。

这是未签名开发包，实际加载扩展/权限弹窗应由你在Chrome安装验收。自动浏览器验证的Chrome API为替身，不代表Chrome商店审核或BOSS授权通过。
